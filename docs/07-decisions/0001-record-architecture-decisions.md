# 1. Record architecture decisions

**Status:** Accepted — 2026-08-02

## Context

This system will outlive the memory of why it was built the way it was. A very
small team, working intermittently, needs to know which decisions were
deliberate and which were accidents.

## Decision

Significant architectural decisions are recorded here as short, numbered,
immutable documents. An ADR is never edited after acceptance; it is superseded
by a later one that explains what changed and why.

A decision is worth an ADR if reversing it would cost more than a day, or if a
future contributor would reasonably ask "why on earth is it like this?".

## Consequences

Reviewers can point at a document instead of re-arguing. Newcomers can read the
reasoning in order.
